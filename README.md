## Google Style Guides

Google Style Guides (o guía de estilo de Google) es un conjunto de normas y recomendaciones oficiales creadas por Google para estandarizar la escritura, la documentación técnica o la programación de código. Pueden acceder a la documentacion oficial [haciendo click aca](https://google.github.io/styleguide/)

## Javadoc

Javadoc es el estándar de la industria para documentar clases de Java. Pueden acceder a la documentación oficial [haciendo click aca](https://www.oracle.com/technical-resources/articles/java/javadoc-tool.html)
